Data sendiri

Muat file RTRW, kawasan hutan, layout mill, atau data lain: ZIP shapefile (berisi .shp .dbf dan sebaiknya .prj), GeoJSON, KML, atau KMZ. File diproses di peramban dan tidak diunggah ke mana pun. Untuk file besar, potong dulu per kabupaten atau area di QGIS.

    Daftar ini ikut berubah saat Anda menggambar atau menggeser titik di peta. Untuk memakai koordinat sendiri, tempel di sini lalu klik Terapkan. Derajat-menit-detik seperti 7°28'19.5"S 112°26'1"E juga terbaca.

    Samakan luas poligon dengan luas di sertifikat atau permohonan. Bentuk dan titik tengah dipertahankan, semua sisi diperbesar atau diperkecil dengan perbandingan yang sama. Gunakan untuk selisih kecil akibat menggambar. Selisih besar biasanya berarti batas lahan belum tergambar dengan benar.

    1. Perbesar peta ke lokasi lahan, lalu klik sudut-sudut batas satu per satu mengelilingi lahan.
    2. Klik titik 1 (kuning) atau tombol Tutup poligon setelah minimal tiga titik.
    3. Geser titik untuk memperbaiki. Klik garis batas untuk menambah titik. Klik kanan atau klik dua kali pada titik untuk menghapusnya.
    4. Tekan Esc saat menggambar untuk membatalkan titik yang belum ditutup.
    5. Isi data proyek, pastikan status Siap diunduh, lalu unduh ZIP dan unggah ke OSS tanpa diekstrak.

    Punya koordinat dari surat ukur atau CAD? Tempel di tab Koordinat. Punya file dari Google Earth? Gunakan tombol Impor.
